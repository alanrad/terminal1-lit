Initials

Use the initials attribute to display text when no image is available.

Image

Provide an image URL to display a photo. Falls back to initials or icon on error.

Shape

Use shape to control the avatar outline: circle (default), rounded, or square.

Icon Fallback

Without image or initials the default person icon is shown. Override it via the icon slot.

Sizing

Control size with the --size CSS custom property.
